This page is the evidence behind a decision that is now closed. It was built to choose the matching gate — the measure that decides which ground-truth traveler a model row is about. Five candidates were scored over all 1737 distinct name pairs in the corpus.

Adopted: ratcliff at a threshold of 0.7. It is what evaluate.name_similarity computes and what evaluate.match_rows thresholds today. cer was also kept, but for a different job — it is the transcription measure, reported as name CER, and it is never used to gate. ned_max, token_f1 and jaro_wink were rejected and are used nowhere in the scorer; they remain here only so the comparison can still be checked.

The choice was not cosmetic: 1101 of the 1737 pairs are contested — between one and four of the five measures accept them, so the measure alone decides the outcome. The reasoning is in The Evaluation Method (“the gate and the transcription measure do different jobs”) and the decision is recorded as settled in Evaluation Guidelines §2.

What the five measures are

measuredefinition behaviour that decided itstatus
ratcliff The larger of a Ratcliff-Obershelp ratio (2M/T, matched characters over combined length, taking the longest common block and recursing either side) and exact token-set overlap |A∩B| / max(|A|,|B|). Symmetric and length-stable, and the token arm rescues reordered names. Not an edit distance: characters stranded across an anchor block cannot match. ADOPTED as the gate
cer 1 − levenshtein(gt, model) / len(gt). A true minimum edit distance, normalized by the reference length. Asymmetric on purpose: appended text is punished as hard as wrong text, and a short name gets almost no tolerance. Right for measuring a transcription, wrong for deciding identity. kept — transcription measure only
ned_max 1 − levenshtein / max(len). The same edit distance, normalized by the longer of the two strings. Symmetric, bounded and length-stable — the principled fix for CER's asymmetry, but it does not buy a different answer often enough to justify changing the gate. It reaches the same accept/reject verdict as ratcliff on 1520 of 1737 pairs (88%), and where the two differ neither is systematically the better call: real misreadings in this register are mostly equal-length substitutions, where Ratcliff-Obershelp and edit distance coincide. rejected
token_f1 Harmonic mean of token precision and recall, tokens paired greedily and counted as matched at ned_max ≥ 0.80. The record-linkage default, and unusable here: a token either clears its internal 0.80 bar or contributes nothing, so one wrong character in a short name collapses the whole score. See milbank/mxlbxnk in the table below — every other measure gives 0.71, token_f1 gives 0.00. rejected
jaro_wink Jaro-Winkler: Jaro similarity with a bonus for a shared prefix of up to four characters. The only genuine alternative, and rejected because its prefix weighting cannot be tuned. Given names repeat across travelers in this register, so a shared prefix carries little information: it rescues a real traveler (tomaso wolseleye/tomaso wodehouse, 0.88) and admits an apparent stranger (giuseppe magaluzzi/giuseppe braganze, 0.90) by the same mechanism — and the stranger scores higher than the genuine match, so no threshold separates them. rejected
