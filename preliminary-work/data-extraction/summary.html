  • B (Guided + Transcription): image + guidance + full transcription.

How scoring works

Scoring is defined in eval_guidelines.html; the equivalence and ignore rules it applies are on the Equivalences and Ignore Rules page, read at run time.

In brief: model rows are paired with ground-truth travelers by name similarity, and F1 counts those pairings — it answers which travelers were found. Name CER is reported beside it and answers how faithfully those names were read: character edits over reference characters, micro-averaged. The two are separate questions and neither substitutes for the other.
Only after the name-matching is the per-field accuracy calculated. Therefore, if a model only matches 50 of the 65 named travelers (across all three pages) it can receive a 100% accuracy score if all 50 fields, across 10 runs match the ground truth.

5. Notes and caveats

  • Gemini 3.1 thinking budget: Gemini 3.1 preview is a thinking model with unbounded default thinking, which caused all 10 Phase A page-36 runs to hit MAX_TOKENS before any JSON was emitted. Resolved by setting thinkingLevel=LOW and max_output_tokens=32768; all current scores reflect successful runs. (thinkingBudget is silently ignored by Gemini 3.1 preview.)
  • Claude extended thinking requires temperature=1 (Anthropic API constraint). All other models run at temperature=0.
  • GPT 5.2 needs response_format=json_object enforcement to avoid degenerate-loop generation at temperature=0. The "image" field was also removed from the response schema after empirical evidence that GPT-5.2 hallucinates hex into a literally-named "image" field.
  • Claude wraps responses in markdown code fences despite the prompt saying not to. A narrow Claude-only fence-strip is applied before parsing — the only tolerance in the otherwise strict-json.loads pipeline.
  • No ground-truth contamination: collection scripts never read files from gt/. The GT enters the pipeline only at evaluation. Format coincidence (e.g. q.m) comes from the prompt's expert-guidance section, not from the GT.
  • Image normalization: all images are auto-oriented (EXIF rotation baked into pixels, tag stripped) before sending. 18 of the 39 document images had orientation=6 EXIF tags; we verified all current providers auto-orient as of 2026-05-06, but normalization is kept as defensive infrastructure.
