Experimental transcription files used for phase B

The page viewer shows the corrected transcription. This page shows the transcription as it stood when the phase-B responses were collected, on 24 June 2026. The two are not the same text, and every phase-B figure in this study is a measurement against the version below — not against the corrected one.

The differences matter because phase B is the transcription condition: a model that faithfully copies an erroneous transcription is scored against ground truth that records the correct reading, and is marked wrong for obeying its input. Where that happens it is a property of this experiment, not a finding about the model.

How the collection-time text was established

This cannot be read off git alone. The transcriptions were first committed on 14 July 2026, three weeks after the phase-B collection of 24 June, so at collection time the files were untracked and git holds no record of that day's contents. What git does show is that the text is byte-identical from its first commit through the commit preceding the corrections, and changes only when the corrections land.

Three independent checks agree that the text below is what was sent:

  1. What the models echoed. Todeschin 250 / 0 in the phase-B checkpoints and 0 / 250 when re-collected against the corrected text; Santi Apostoli absent in phase B, 128 occurrences on re-collection.
  2. Input token counts for the same model and image across the two collections. Page 36 falls by 568 tokens (Claude) and 560 (Gemini) — the signature of the &nbsp; runs that only the as-collected version contains. Page 39 rises by 26 and 12, matching the added parish line. GPT's counts move erratically and carry no weight here.
  3. Ground truth alignment. Each reading difference above resolves toward the ground truth, which is what a correction pass would do.

The honest limit: an edit made on disk between 24 June and 14 July and never committed would be invisible to all three checks.
